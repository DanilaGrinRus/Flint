# Mainnet readiness / реальные деньги

**Статус: НЕ ГОТОВО. DEV BUILD, не аудирован, не для реальных средств.**
Этот документ — отдельный гейт: он не разрешает mainnet, а фиксирует, что должно
быть выполнено до первой реальной транзакции.

Официальная политика: testnet по умолчанию; mainnet — только вручную; обозначение
сборки «пригодна для реальных средств» — только после [фазы 6](ROADMAP.md#фаза-6--релиз)
и внешнего аудита. До этого в README/STATUS/UI остаётся предупреждение.

## Уровни готовности

| Уровень | Сейчас | Комментарий |
|---|---|---|
| Testnet, ежедневная работа | ✅ да | Основной режим, живой lifecycle прогонялся |
| Mainnet: нода, адрес, синхронизация | ⚠️ технически | Проверялся запуск ноды и формат `grin1…`, без транзакций |
| Mainnet с реальными деньгами | ❌ нет | Нет аудита, mainnet dry-run и подписанных сборок; Argon2id есть без релиза |
| Публичный релиз для денег | ❌ нет | Фаза 6 не начата |

## P0 — блокеры, без которых mainnet запрещён

- [ ] **Внешний аудит** кода и интеграции с `grin-wallet`/`grin`; письменное
      ревью модели угроз; исправление найденного.
- [ ] **Argon2id-конверт seed** с версионированием, миграцией и тест-векторами;
      PBKDF2-100 upstream больше не единственная защита файла seed.
      *Без релиза, 0.1.69: конверт у обоих бэкендов, миграция legacy по кнопке,
      откат и mainnet-гейт есть; kill-дрилл M0–M5 автоматизирован, Argon2id для
      ключа истории сделан, живая миграция с нодой прогнана; `.flint-seed.lock`
      удерживается на весь `prepare → open → commit/rollback` и на смену
      пароля/ремонт/удаление. Осталось: внешнее человеческое ревью, обрыв
      питания и координация с внешним `grin-wallet` — [ARGON2ID.md](../historical/ARGON2ID.md)
      §13.*
- [ ] **Mainnet dry-run под наблюдением**: малая сумма, полный
      send → receive → finalize → confirmation; отдельно restore из фразы в
      чистый каталог с независимой сверкой адреса и баланса.
- [x] **Graceful shutdown**: `NodeManager::stop` отправляет Ctrl-Break в
      скрытую консоль ноды (`CREATE_NEW_PROCESS_GROUP`) и ждёт завершения;
      `kill` остаётся fallback. Тест `starts_and_stops_bundled_node` проверяет
      `Shutdown complete` в логе, `starts_again_after_a_hard_kill` — рестарт
      после жёсткого kill.
- [x] **Backup drill**: runbook [BACKUP.md](../operations/BACKUP.md), автотест restore в
      другом корне. Осталось ручное повторение на чистой машине.
- [ ] **Отказоустойчивость**: kill ноды/рестарт и ошибка записи pending-файла
      (старая запись остаётся целой) проверены; power-loss в каждой точке
      журнала, реальный disk-full, битая цепь, офлайн и флаппинг сети — ещё
      нужны стендовые сценарии.
- [ ] **Релизная инженерия**: есть `tools/release.ps1` с
      `-RequireSigned`, `tools/check-node-version.ps1`, `tools/sbom.ps1`
      (CycloneDX), `build-info.json`, SHA-256 manifest и CI; подпись без
      сертификата и reproducible build с внешними штампами времени остаются.
- [ ] **CI**: `.github/workflows/windows.yml` (fmt/check/tests/build/selftest)
      и `tools/ci.ps1`; добавлены `cargo vendor` и `fetch-node`/`fetch-wallet` для
      чистого runner. Успешного прогона на GitHub-hosted runner ещё нет; живой
      testnet-job требует self-hosted runner с нодой.
- [ ] **Проверка адреса и суммы**: копирование, полная строка адреса, QR, лимит
      по `spendable`, явная комиссия, обязательный чекбокс и подтверждение
      последних 8 символов адреса есть; логика проверяется
      `tools/check-address-tail.mjs`, QR — `tools/check-qr.mjs`. Живой сценарий
      проверки подмены буфера обмена ещё не сделан.
- [x] **Смена пароля/удаление кошелька**: живой прогон на **mainnet-каталоге
      без средств** (embedded): неверный старый пароль отклонён, смена пароля +
      переупаковка ключа истории, повторное открытие новым паролем, удаление в
      `trash/mainnet/`. RPC-удаление из UI теперь тоже останавливает процесс,
      снимает Tor и переносит каталог в `trash/`; ручной перенос больше не нужен.

## Внешние блокеры, которые нельзя закрыть в этой сессии

Это не «забытые» пункты, а работы, требующие денег, сертификата, отдельного
стенда или человека-аудитора:

- **Внешний аудит** кода/интеграции и письменное ревью модели угроз — нужен
  независимый аудитор; внутренние тесты его не заменяют.
- **Mainnet dry-run** малой суммой с полным send → receive → finalize →
  confirmation и restore из фразы — требует реальных средств и наблюдения.
- **Power-loss/disk-full/битая цепь** — нужен отдельный destructible-стенд;
  текущие kill/restart и ошибка записи pending это не заменяют.
- **Backup drill на чистой машине** — ручной шаг вне текущего окружения.
- **Подпись Authenticode и reproducible build с внешними штампами времени** —
  нужен сертификат и изолированный сборочный стенд; артефакты 0.1.69 сейчас
  `signed:false`.
- **Чистый GitHub-hosted CI** — workflow и `tools/ci.ps1` есть, но успешного
  прогона на GitHub-hosted runner в этой сессии не было; живой testnet-job
  требует self-hosted runner с нодой.
- **Внешнее человеческое ревью Argon2id** и координация с внешним
  `grin-wallet` — внутренний kill-дрилл и lock не заменяют ревью.

Остающийся локальный пункт — QR и живой сценарий проверки подмены адреса в
буфере обмена; подтверждение последних 8 символов уже добавлено.

## Что уже сделано в пользу mainnet

- Сети и ключи разделены: `testnet/` и `mainnet/` не пересекаются; mainnet не
  стартует случайно.
- Журнал транзакций, идемпотентная финализация, сверка суммы с цепью,
  restore/scan, крэш-границы testnet.
- Owner API с Basic-auth, ACL секретов, zeroize пароля/фразы, loopback, прокси
  без CORS для управляемой ноды.
- Парольная политика (12+, классы, запрет простых слов) как смягчение PBKDF2.
- Argon2id-конверт seed у обоих бэкендов: пароль пользователя больше не уходит в
  PBKDF2-100 upstream; legacy-кошельки мигрируются по кнопке, mainnet без
  конверта не открывается (0.1.69).
- 277 автотестов (28 ignored); живой testnet-lifecycle.
- Нода останавливается через Ctrl-Break и `Shutdown complete`; жёсткий kill и
  повторный запуск покрыты тестом.
- `tools/release.ps1` + SBOM + SHA256SUMS + CI; артефакты 0.1.69 собраны, но
  **не подписаны**.
- Backup runbook [BACKUP.md](../operations/BACKUP.md); mainnet-каталог без средств прошёл
  создание/смену пароля/удаление.

## Правило

Пока чек-лист P0 не закрыт и аудит не подписан, Flint **не должен** получать
реальные GRIN. Любая «проверка малой суммой» до аудита — нарушение этого гейта.
