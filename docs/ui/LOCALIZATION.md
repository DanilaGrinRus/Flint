# Локализация UI

Статус: **английский UI не показывает русский текст.** Статические строки идут через
Slint `@tr`, динамические — через `i18n.rs` (264 записи каталога). Непереведённая
русская строка в EN-режиме заменяется английским generic-сообщением и пишется в лог;
это страховка, а не «перевод всего на свете». Документация проекта остаётся русской.

## Как это устроено

- Язык по умолчанию — русский: строки в `ui/spike.slint` служат gettext `msgid`.
- Английский каталог — `crates/slint-ui/lang/en_US/LC_MESSAGES/flint-slint.po`.
  Имя папки не `en`: Slint считает `en`/пустую строку выбором языка по умолчанию
  (то есть русского), поэтому английский вынесен в `en_US`.
- `crates/slint-ui/build.rs` собирает переводы в бинарь
  (`with_bundled_translations("lang")`, контекст `None`), отдельных файлов при
  упаковке не требуется.
- Выбор языка хранится в файле `ui-language` в корне данных (`ru`/`en`), не в
  секретах. В настройках есть список «Русский / English»; **применяется после
  перезапуска**.
- При старте `flint-slint` читает `ui-language` и после создания первого
  компонента вызывает `slint::select_bundled_translation("en_US")`. До создания
  компонента выбор невозможен: Slint регистрирует каталог в этот момент.

## Статические строки

- 109 строк `text`/`placeholder-text`/`title` через `@tr(...)`: навигация, кнопки,
  подписи полей, основные диалоги.
- 29 `accessible-label` также обёрнуты в `@tr`.
- Справка по восстановлению — overlay «Как восстановить кошелёк» с четырьмя
  абзацами и закрытием.
- Названия языков в списке остаются «Русский»/«English» намеренно.

## Динамические сообщения

- `crates/slint-ui/src/i18n.rs` — точные пары `ru → en`, шаблоны с `{}`/`{name}`
  (захват и подстановка), `set_english`/`tr`/`tr_with`.
- 264 записи: статусы кошелька/ноды, скан, Tor/мосты, буфер, activity,
  pending-уведомления, ошибки `flint-core` (`error.rs`, `node.rs`, `service.rs`,
  `config.rs`, `gateway.rs`), `flint-runtime`, диалог выбора каталога, основные
  callback-сообщения.
- Все русские строки, попадающие в `set_*_error`/`set_*_note` и в форматтеры UI,
  проходят через `tr`; английская ветка есть у `node_line`.
- **Fallback:** если строка с кириллицей не найдена в каталоге, в UI уходит
  `Operation failed; details are in the log`, а исходная строка пишется в stderr.
  Поэтому английский интерфейс не показывает русский, но редкая ошибка теряет
  детализацию до записи в лог. Это осознанный компромисс 0.1.69.

## Что ещё не переведено

- Документация проекта остаётся русской; английского README нет.
- Редкие внутренние сообщения вне каталога показываются generic-текстом, а не
  точным переводом; каталог пополняется по логам `i18n: missing English translation`.
- NVDA/Narrator, IME и Tab/DPI — внешний PS-11; полный a11y-аудит не заявляется.

## Проверки

- `every_tr_literal_has_an_english_translation` — каждый `@tr`-литерал имеет
  `msgid` в каталоге.
- `english_catalog_is_non_empty` — каталог не пуст и помечен `en_US`.
- `ui_language_round_trips_and_defaults_to_russian` — файл языка читается/пишется,
  неизвестный язык отвергается.
- `i18n::tests::exact_and_template_translation`, `nested_error_is_translated`,
  `core_error_is_translated` — точные/шаблонные пары и вложенные ошибки.
- `english_never_leaks_cyrillic` — fallback не возвращает кириллицу.
- Запуск `flint-slint --data <tmp>` с `ui-language=en` печатает
  `ui language: en_US selected`; при старте в stderr нет
  `i18n: missing English translation`.

## Как добавить строку

1. Для `.slint`: обернуть `text: @tr("Текст");` и добавить `msgid`/`msgstr` в
   `lang/en_US/LC_MESSAGES/flint-slint.po`.
2. Для Rust: добавить пару в `CATALOG` в `crates/slint-ui/src/i18n.rs`; для
   форматированной строки сохранить порядок `{}`/`{name}`.
3. Прогнать `cargo test -p flint-slint --bin flint-slint` — тесты полноты
   `@tr`-каталога и запрета кириллицы.
4. Проверить EN-прогон: в stderr не должно быть
   `i18n: missing English translation` для затронутого сценария.
