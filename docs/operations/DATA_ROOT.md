# Каталог данных и несколько кошельков

Актуализировано: 2026-10-28. Сеть по умолчанию — testnet; mainnet запрещён до
официальных гейтов.

## Несколько seed в одном окне

Flint поддерживает несколько профилей в одном окне. У каждого именованного профиля
своя seed-фраза, пароль, кошелёк, pending/state и messenger/history. В поле «Имя
кошелька» укажите новое имя из латиницы, цифр, `-` или `_`, сохраните настройки, затем
создайте или восстановите независимый seed.

Одновременно активен один профиль. Переключение блокирует прежний контекст и не является
одновременным запуском нескольких кошельков. Профиль `default` сохраняет прежний путь и
не требует миграции. Не запускайте копии одного seed одновременно: после такого
эксперимента нужен полный rescan.

## Где данные по умолчанию

- Portable: `data\` рядом с `Flint.exe`.
- Без portable-маркера: `%LOCALAPPDATA%\Flint`.
- Параметр `--data <путь>` и переменная `FLINT_DATA_DIR` имеют приоритет над настройкой.

Внутри корня находятся `<сеть>\wallet`, `<сеть>\wallets`, `<сеть>\node`, state, pending,
RPC и messenger/history. Сети и профили изолированы каталогами.

## Выбрать другой каталог

1. Откройте «Настройки» → «Каталог данных ноды и кошельков».
2. Введите абсолютный путь или нажмите «Обзор…».
3. Нажмите «Применить при перезапуске».
4. Закройте и снова запустите Flint.

До перезапуска текущий процесс продолжает использовать прежний корень. Кнопка
«Стандартный» подставляет путь по умолчанию. Пустое поле сбрасывает сохранённый override.
Если корень задан через `--data` или `FLINT_DATA_DIR`, настройка заблокирована: измените
параметр запуска.

**Flint не копирует и не удаляет данные при смене корня.** Если новый каталог пуст, после
перезапуска появится пустой кошелёк и новая цепь — это не доказательство потери старых
данных. Прежний каталог остаётся на месте.

## Перенести существующие кошельки и цепь

1. Дождитесь завершения операций и закройте Flint.
2. Скопируйте содержимое прежнего корня в новый, сохранив структуру `testnet`, `mainnet`
   и остальных каталогов. Не запускайте две копии одного seed одновременно.
3. Запустите Flint и выберите новый корень, затем перезапустите приложение.
4. Проверьте имя профиля и адрес. После копирования выполните полный «Сканировать» и
   проверьте предупреждение об изменении баланса, если оно появится.

Старые файлы удаляйте только после успешной проверки и отдельного решения; эта настройка
их не удаляет.

## Селектор и ошибки

- В portable-сборке выбор сохраняется в `data-root.json` рядом с `Flint.exe`, вне `data`.
- В обычном режиме файл находится в стандартном корне `%LOCALAPPDATA%\Flint`.
- Повреждённый или относительный путь в селекторе не игнорируется: приложение не открывает
  вместо него другой кошелёк. Исправьте `data-root.json` при закрытом Flint либо удалите
  только этот селектор, чтобы вернуться к стандартному корню.
- Относительные пути и обычные файлы вместо каталога отклоняются. Сохранение выполняется
  атомарно с owner-only ACL.

Ручная интерактивная приёмка нового UI не проведена; логика селектора покрыта regression,
сборка и selftest проверены отдельно.
