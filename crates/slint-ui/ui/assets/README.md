# Flint brand assets

Mark A «Складка» — плоская мята, диагональный разрез и загнутый уголок.

- `flint-mark.svg` — векторный исходник.
- `flint-mark-16/24/32/48/64/128.png` — растровые размеры.
- `flint-mark.ico` — многоразмерная иконка Windows.
- В UI используется `flint-mark-48.png`; для 16/24 допускается упрощённая форма.

Технические имена `flint-*`/`FLINT_*` и каталоги данных не переименовываются.
